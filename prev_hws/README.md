# Previous homework snapshots

`hw0/` through `hw3/` are ordinary folders in this repository. They include the available source, notebooks, tests, figures, and MNIST data files from the earlier assignments. They are kept here for reference while the graph project gets its own Needle baseline.

The earlier Git history stored these folders as links to separate repositories. This copy tracks their files directly, so a clone does not need those repositories. Generated caches, local build output, and compiled extensions are excluded; rebuild an extension from its source when needed.

These snapshots do not include a completed HW4 implementation. See the project [README](../README.md) for what still needs to be in the shared setup commit.
