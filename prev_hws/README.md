# Previous homework snapshots

`hw0/` through `hw4/` are ordinary folders in this repository. They include the available source, notebooks, tests, figures, and MNIST data files from the earlier assignments. The HW4 Needle baseline stays in `hw4/`.

The earlier Git history stored these folders as links to separate repositories. This copy tracks their files directly, so a clone does not need those repositories. Generated caches, local build output, and compiled extensions are excluded; rebuild an extension from its source when needed.
